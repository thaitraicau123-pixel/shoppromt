# BỘ PROMPT TẠO ASSET SPRITE SHEET HOÀN CHỈNH — PHONG CÁCH SOUL KNIGHT & DARK FANTASY
## (4 ANH HÙNG + 200 QUÁI VẬT DARK FANTASY)

> **Mô tả:** Tài liệu này chứa bộ prompt hoàn chỉnh để tạo từng nhân vật anh hùng và 200 loại quái vật Dark Fantasy theo đúng phong cách chibi pixel art của Soul Knight. Mỗi prompt đều yêu cầu xuất ra một asset sprite sheet hoàn chỉnh gồm đầy đủ các trạng thái animation để đưa thẳng vào game (Idle, Walk/Move, Attack/Cast, Hurt & Death).

---

## 1. Khung Prompt Chuẩn (Master Style & Layout)

Mọi prompt bên dưới đều tuân theo cấu trúc chuẩn sau (bạn có thể giữ nguyên hoặc tùy chỉnh số frame/nền):

- **Phong cách:** `2D pixel art game sprite sheet, Soul Knight chibi style, top-down 3/4 view, cute big-head stubby-body proportions, thick dark pixel outlines, crisp 16-bit/32-bit pixel art, vibrant cel-shaded colors`
- **Bố cục Animation (4 hàng × 4–6 cột = Asset hoàn chỉnh):**
  - **Hàng 1 (Idle):** 4 frame đứng yên nhún nhẹ / thở.
  - **Hàng 2 (Move/Walk):** 4–6 frame di chuyển / chạy / bay.
  - **Hàng 3 (Attack/Cast):** 4–6 frame vung vũ khí, bắn cung hoặc thi triển phép kèm hiệu ứng (slash arc, projectile, magic glow).
  - **Hàng 4 (Hurt & Death):** 2 frame trúng đòn (nháy trắng/giật lùi) + 3 frame ngã gục / tan biến.
- **Kỹ thuật xuất hình:** `solid flat dark slate gray background (#2B2D42), evenly spaced grid, consistent character scale across all frames, no text, no labels, no grid lines`

## 4. Mẹo Cắt Sprite & Đưa Vào Game (Unity / Godot / Aseprite)

1. **Tách nền trong suốt:** Mọi prompt đều cố định nền `#2B2D42` để bạn dễ dùng Color Key / Magic Wand hoặc script Python (PIL / rembg) xóa nền hàng loạt thành PNG trong suốt.
2. **Cắt lưới tự động (Grid Slicing):**
   - Trong **Unity** (`Sprite Editor → Grid By Cell Count: 4×4` hoặc `4×6`), đặt Pivot ở `Bottom-Center` để nhân vật đứng chuẩn trên mặt sàn 3/4.
   - Trong **Godot** (`Sprite2D → Animation → Hframes: 4, Vframes: 4`), gán Frame Coords theo từng dòng animation.
3. **Đồng bộ kích thước Pixel:** Nếu cần ghép nhiều quái vào cùng một scene, scale theo chiều cao chuẩn (quái thường `~32×32 px` hoặc `48×48 px`, Boss `~64×64 px` hoặc `96×96 px`) bằng thuật toán **Nearest-Neighbor** để giữ nét pixel sắc cạnh, không bị mờ nhòe.
